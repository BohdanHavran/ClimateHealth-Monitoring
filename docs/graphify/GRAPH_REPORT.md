# Граф коду

23.11.2026. Реально викликано встановлений Graphify через Python API та CLI `export html`. Нових пакетів Graphify не встановлювали. `scripts/build_code_graph.py` аналізує тільки Python у корені, `scripts/` і `tests/`; секрети, CSV, архіви, `.venv` та академічні матеріали виключені.

Оновлення після модулізації фази 2: 33 Python-файли, **280 вузлів, 615 ребер, 11 спільнот**. Уключено `climate_health/`, `ml_service/`, scripts і tests; точний перелік — `summary.json`. `graph.json` придатний до подальших запитів, `graph.html` — інтерактивне локальне представлення. HTML/JSON/cache є generated local outputs і виключені з Git; звіт і summary можна публікувати. Початковий прогін фази 1 мав 162 вузли/310 ребер — ці числа більше не описують актуальний граф.

Це AST-граф, не повна модель системи. Екстрактор повідомив, що `app.py` не дав символів: його Streamlit top-level потік вивчено вручну. SQL, Jinja, JavaScript, runtime wiring Flask і зовнішні сервіси не відновлюються цим проходом повністю. Відсутність ребра не доводить відсутності залежності; кількість вузлів не є оцінкою якості. Архітектурні висновки й ручні схеми — `../ARCHITECTURE.md`, `../TECHNICAL_AUDIT.md`.
