# ADR 0001: основний вебконтур Flask і MySQL

Дата: 23.11.2026. Статус: рекомендовано для поетапної реалізації; початкова стабілізація виконана без заміни фреймворку.

Проблема: одночасна зміна мови, фреймворку й інтерфейсу знищила б можливість перевірити збереження поведінки. Поточні fuzzy, SQL і маршрути вже написані Python, а продуктивнісних доказів необхідності іншого runtime немає.

Рішення: модульний Flask із провайдерами, сценаріями й репозиторіями; тільки MySQL. FastAPI використати для незалежного ML API після появи моделі. SQLAlchemy/Alembic розглядати під час виділення репозиторіїв, не змінювати існуючу БД без перевіреної міграції.

Наслідки: мінімальна початкова міграція, але валідацію/OpenAPI основного API потрібно підтримувати явно. Перегляд ADR можливий після контрактних тестів і вимірювання навантаження. Порівняння альтернатив — TECH_STACK_DECISIONS.md.
