# ADR 0003: координатна погода та незмінний HRI

Статус: реалізовано для дослідницького локального застосунку, 23.11.2026.

Dashboard/карта мають працювати без повторного використання скомпрометованого OpenWeather ключа. Для явних координат додано окремий Open-Meteo adapter з [ліцензією CC BY 4.0](https://open-meteo.com/en/licence) і [non-commercial API terms](https://open-meteo.com/en/terms). Provider URL фіксований, параметри finite/range validated, units перевірені. Немає довільної адреси для HTTP-запиту або запису погоди в БД. Видима attribution у UI обов’язкова.

Документація й реальний API підтвердили current shortwave_radiation у W/m². Використовуємо це модельне значення замість апроксимації за хмарністю в новому шляху. Підписуємо model data, час показників, retrieval time та cache state; не оголошуємо станційними вимірюваннями. Для legacy city OpenWeather збережено попередню поведінку й окремий ключ у локальній конфігурації.

Нечіткий engine, 27 правил і clipping domain не змінюються. Новий UI відображає вхідні та effective values і не перетворює HRI на відсоток медичного ризику. Джерело погоди й діапазони моделі потребують наукової валідації; нове джерело саме по собі не доводить придатності HRI для здоров’я.

Кеш/quotas локальні процесу, тому production multiworker потребує іншого глобального бюджету. Відмова провайдера не замінюється fake values. Явне введення координат не створює вигаданого MySQL place; історія без географії не геокодується. Публічні OSM tiles використовуються лише для звичайного видимого шару з attribution, без bulk download/offline cache.
