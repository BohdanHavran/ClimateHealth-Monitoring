# Огляд попереднього GitHub-проєкту

Станом на 23.11.2026 переглянуто публічний репозиторій [BohdanHavran/Diploma](https://github.com/BohdanHavran/Diploma) у режимі читання. Поточна гілка, відображена GitHub, — `infrastructure`, показано 26 комітів. Повний SHA поточного коміту й перелік усіх гілок через доступний вебперегляд не відображені; повний аудит інших гілок, історії секретів і всіх файлів неможливий. Завантаження або копіювання проєкту не виконувалося.

Додаткова спроба read-only GitHub API через вебінструмент не повернула metadata, branches або recursive tree. У локальній пісочниці `git ls-remote --symref` і запит GitHub API завершилися помилкою мережевих дозволів; спроба запросити виконання `git ls-remote` поза пісочницею була перервана до отримання результату. Відповідно, підтвердити SHA голови гілки, повний перелік гілок та workflows не вдалося; версійні і конфігураційні висновки обмежені наведеними нижче доступними сторінками.

На верхньому рівні доступні `main.tf`, `provider.tf`, `variable.tf`, порожній `output.tf` і `module/`. Кореневий [main.tf](https://github.com/BohdanHavran/Diploma/blob/infrastructure/main.tf) посилається на модулі VPC, registry, MySQL і приватного bucket; окремо містить інфраструктуру оркестратора, яка не використовується в новому проєкті. У прикладі MySQL задано приватну мережу, двигун MySQL 8 і щотижневе вікно обслуговування. Код bucket вказує приватний ACL і `force_destroy=false`, registry має окрему підписку. [provider.tf](https://github.com/BohdanHavran/Diploma/blob/infrastructure/provider.tf) параметризує доступ до DigitalOcean і Spaces.

Корисні ідеї — відокремити мережеві налаштування, середовище та конфігурацію, позначати приватні buckets і зберігати явну заборону автоматичного руйнування stateful даних. Це принципи для самостійної реалізації. Код і секрети не переносилися; наявність приватного ACL не доводить перевіреної конфігурації доступу.

У старому `main.tf` для бази `create_firewall=false`, а список правил містить широке джерело. Необхідність перевірити фактичне застосування й поведінку цих параметрів не дає підстав копіювати конфігурацію. Перенесення типових значень, регіонів, паролів, ключів, версій та firewall-правил без окремої перевірки заборонене.

Вебперегляд не відкрив вміст `module/` і сторінку гілок; Dockerfile, Actions workflows, реалізацію модулів і наявність конфігурацій в інших гілках не встановлено. Позначення відсутності не є доказом їх відсутності в репозиторії. Віддалена інфраструктура не перевірялась.
